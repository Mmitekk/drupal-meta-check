Drupal Meta Check

Живые title / description / H1 против сохранённой базы сравнения — для любого сайта. Встроен отчёт: —. Свой сайт или список ссылок — в блоке «Своя проверка» под панелью. Кнопка сверху проверяет страницы и подсвечивает, что изменилось; черновики title/description вписываются прямо в таблицу.

Своя проверка — вставить сайт или список ссылок

Порядок работы: создайте проверку → дождитесь живой проверки → нажмите «◉ Зафиксировать базу», чтобы текущие значения стали базой сравнения. Дальше после любых правок на сайте жмите «Проверить актуальные данные» — увидите отличия от зафиксированного снимка. Список, снимок и черновики хранятся в этом браузере.

Данные отчёта (заменить / вернуть встроенные)

Вставьте JSON-массив страниц аудита (поля: url, title, description, h1, code, dupTitle, dupDescription, textLength — обязательна минимум url) и нажмите «Заменить». Данные сохранятся в этом браузере; черновики по совпадающим URL сохранятся.

# URL Код Яз. Дуб. T Дуб. D Текст Сайт сейчас Сверка H1 / T / D

«Сайт сейчас» — страница загружается через публичные CORS-прокси (allorigins → corsproxy.io → codetabs → cors.eu.org → r.jina.ai), поэтому HTTP-код ответа прокси не показывает: статус определяется по содержимому. «? 404» — Drupal на несуществующем адресе отдаёт главную страницу (title/каноническая главной): инструмент помечает такие случаи. Сравнение «мягкое» игнорирует регистр, пунктуацию и лишние пробелы; выключите галочку, чтобы сравнивать посимвольно. Черновики и live-результаты хранятся в localStorage браузера и никуда не отправляются.

Источник отчёта: выгрузка аудита Топвизор, встроена в файл при сборке. Заменить — блок «Данные отчёта» выше.
